# QDU 校园导航（QDU-Nav）

面向**青岛大学**的校园服务聚合入口（非官方演示站），受福师大社区项目 NextFStar 启发，功能对齐并采用**亮色清新**界面风格。

## 功能

| 应用 | 说明 |
| --- | --- |
| 🗓️ 课程表 | 班级课表（周视图）与教室课表，覆盖 8 个示例班级 |
| 🪪 新生学号查询 | 考生号 + 姓名 + 证件号后 6 位 + 验证码，演示查询 |
| 💪 体测成绩计算器 | BMI 计算 + 体重评估，本地保存大一到大四记录 |
| 📅 校历 | 官方校历入口 + 学期时间线参考 |
| 🍜 今天吃什么 | 随机推荐菜品 + 食堂一览 + 菜品库（含青岛特色） |
| 🧭 教室导航 | 搜索教室、查看校区/楼层分布与路线指引 |
| 🎯 青大知多少 | 校园知识问答小游戏（校史/校区/设施） |
| 🎡 美食轮盘 | 食堂美食转盘抽奖小游戏 |

## 技术栈

- Vue 3（Composition API）+ Vite（Rolldown 可选）
- 亮色主题：青大蓝 `#1b66c9` + 白色卡片，移动端优先
- 计数器组件（CountUp 数字滚动动画）与各应用统计
- 数据层适配器（`src/api/mock.js`）模拟后端，可替换为爬虫后端

## 运行

```bash
npm install
npm run dev      # 本地预览
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

## 数据对接

- **内置示例数据**：开箱即用，位于 `src/data/`。
- **真实数据爬取**：见 [`crawler/`](crawler/README.md)。
  - 教务课表/成绩：正方教务系统 `jw.qdu.edu.cn`（模拟登录）
  - 校历/公告：教务处官网 `jwc.qdu.edu.cn`（公开抓取）
  - 学号查询：正方系统内查询（带验证码，需人工识别）
  - 演示模式：`python qdu_crawler.py --mock`
