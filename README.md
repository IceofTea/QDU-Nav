# QDU 校园导航（QDU-Nav）

面向**青岛大学**的校园服务聚合入口（非官方演示站），受福师大社区项目 NextFStar 启发，采用**亮色清新**界面风格。

## 功能

| 应用 | 说明 |
| --- | --- |
| 📢 校园动态 | 教务处官网通知与动态**实时同步**（抓自 jwc.qdu.edu.cn） |
| 🗓️ 课程表 | 官方课程总表 + 真实课表查询（班级/课程/教师，解析自教务处 2026 春季课程总表 xlsx） |
| 📅 校历 | 官方校历入口 + 学期时间线参考 |
| 🧭 教室导航 | **空教室实时查询** + 教室一周占用表 + 分步路线 |
| 🍽️ 食堂空座率 | 各食堂实时空座人数（框架，待摄像头数据接入） |
| 🪪 新生学号查询 | 官方录取查询入口 + 演示查询 |
| 💪 体测成绩计算器 | BMI 计算 + 体重评估，本地保存大一到大四记录 |
| 🏛️ 学校官网 | 官网与各学院官网大全 |
| 🍜 今天吃什么 | 随机推荐菜品 + 食堂一览 + 菜品库（含青岛特色） |
| 🎯 青大知多少 | 校园知识问答小游戏（校史/校区/设施） |
| 🎡 美食轮盘 | 食堂美食转盘抽奖小游戏 |

## 技术栈

- Vue 3（Composition API）+ Vite
- 亮色主题：青大蓝 `#1b66c9` + 白色卡片，移动端优先
- 原生 Node 网关（`server/index.mjs`）：抓取教务处官网并解析课程总表 xlsx（Python + openpyxl）

## 运行

```bash
npm install
npm run build    # 构建到 dist/
node server/index.mjs   # 本地网关 8787，静态托管 dist + /api 接口
```

## 数据说明

- **官方实时**：校园动态、校历、课程总表（抓自 jwc.qdu.edu.cn）；课表数据 = 官方《2026 年春季学期课程总表》xlsx 解析（5932 条排课、525 间教室）。
- **演示数据**：课程表（个人）、学号查询（需登录教务/招办，附官方入口）。
- **本地工具**：体测 · 吃什么 · 问答 · 轮盘。
- **食堂空座率**：名单与营业时间为青岛大学后勤管理处官方信息（21 个食堂），实时人数待摄像头数据接入。

## 部署

- 本地：`node server/index.mjs`，访问 `http://localhost:8787`
- GitHub Pages：`.github/workflows/deploy.yml` 自动构建 `dist/` 并部署（推送 main 分支触发），需在仓库 Settings → Pages 将 Source 设为 **GitHub Actions**。
