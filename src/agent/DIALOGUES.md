# 十组标准对话剧本（演示彩排 / 回归参考）

> 用途：① 答辩现场按 D1 → D3 → D8 → D9 组合演示（4 分钟）；
> ② 每次大改后按剧本口头过一遍做人工回归。机器回归见 `scripts/smoke-community.mjs`。

## D1 · 今日简报（日常高频）
- **用户**：`今日简报`
- **路径**：意图 `wf.briefing`（置信 100）→ 3 步（读本机记忆 → 拉课表与通知 → 生成）
- **画面**：置信度徽标 + 耗时 + 执行轨迹折叠"3 步 · 0.6s" + 简报卡（课程/日程/通知三段）

## D2 · 空教室（数据 + 诚实兜底）
- **用户**：`哪里有空教室自习`
- **路径**：`wf.findRoom` → 解析节次 → 网关/快照查询 → 清单卡
- **画面**：卡片 note 显示"实时网关未启动已回退快照（永不白屏）"——降级也是演示点

## D3 · 计划模式（WorkBuddy 式）
- 切 📋计划 → `哪里有空教室` → **先出执行计划卡**（3 步预览 + ✓开始执行 / ✕取消）
- 输入"开始执行" → 再跑 D2 流程
- **画面**：模式标识条 + 计划卡边框高亮（与直达模式视觉区分）

## D4 · 多轮澄清（写操作人在回路）
- `提醒我` → 追问"什么时间？" → `明天下午三点开会` → **确认卡** → 点 ✓ 写入
- **画面**：确认/取消双按钮；取消即"已取消，没有做任何改动"

## D5 · 校园墙悬赏
- `发悬赏 我需要数据结构往年真题` → 确认 → 发布卡（赏金标注）→ 打开悬赏分区

## D6 · 失物招领
- `我丢了校园卡` → 类型判定"寻物" → 敏感词双端校验 → 失物分区发布成功卡

## D7 · 签到与积分
- `签到` → +2 积分卡 → `我的积分` → 钱包明细 + 连续签到天数

## D8 · 协作看板（点题，必演）
- `协作看板` → 用户 Agent 执行数 + 维护 Agent 能力矩阵 + 评论/帖子/反馈/举报统计
- **画面**：双 Agent 飞轮量化卡——这是标题「基于 AI Agent 协作维护」的可视化兑现

## D9 · 反馈回流闭环（管理台联动）
- `提交反馈 简报希望有天气` → 上报 `/api/feedback`
- 接着演示：暗门进管理台 → 「👎 反馈」立即看到 → 标记已处理（审计留痕）

## D10 · 云脑降级（防御演示）
- 未配置云脑时问无关闲话 → **秒回**本地引导（layer=none，不干等）
- 管理台「🧠 云脑」填 Key → ⚡测试连接成功 → 同类问题升级云端（layer=cloud）
- **话术**："没配大模型也完全可用，配了自动变强——密钥只在服务端。"
