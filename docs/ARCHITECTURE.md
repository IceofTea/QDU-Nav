# 架构白皮书 · 通用校园导航（QDU-Nav-agent）

> 读者：评审专家 / 新维护者 / 新 AI Agent。本文回答三个问题：
> 系统长什么样、为什么这样长、改哪里不会塌。

## 1. 分层总览

```
┌─────────────────────────────────────────────────────────┐
│ L5 入口层  首页对话框 · ChatDock 悬浮舱 · Assistant 全屏页 · 语音 │
├─────────────────────────────────────────────────────────┤
│ L4 智能体层 intents(40+) → faq(20) → 应用检索（三层识别）        │
│             engine 状态机（澄清 / 确认 / 计划三态）· 云脑 /api/chat│
│             workflows(27) 步骤执行 + 结果卡片 + 执行轨迹回放      │
├─────────────────────────────────────────────────────────┤
│ L3 应用层   apps.js 注册表(24 应用) ↔ router.js 双登记          │
│             导航 / 课表 / 校园墙 / 提醒中心 / 社区洞察 / 换校向导… │
├─────────────────────────────────────────────────────────┤
│ L2 社区层   src/wall/（config 分区·api 双轨·components 五件套）   │
│             server/community.mjs 评论/墙/投票/反馈/敏感词/云脑代理 │
│             /管理API · JSON 原子落盘 · 敏感词双端拦截             │
├─────────────────────────────────────────────────────────┤
│ L1 数据层   crawler → 6h 快照 → apiFetch 网关优先              │
│             → staticFallback 快照兜底（纯静态托管永不白屏）        │
└─────────────────────────────────────────────────────────┘
```

## 2. 关键设计决策（及理由）

| 决策 | 理由 | 放弃了什么 |
|---|---|---|
| 注册表式应用（apps.js + router 双登记） | 换校不碰内核；应用热插拔 | 约定式路由的隐式便利 |
| 网关优先 + 快照兜底 | 纯静态托管也能全功能 | 静态模式的实时性（用 15~20s 轮询补偿） |
| 智能体三层本地识别 | 零密钥零成本、离线可用、评委现场不依赖网络 | 开放域问答上限（云脑可升级） |
| 评论/墙 JSON 落盘 | 无数据库即可跨用户共享；迁移成本低 | 高并发写入（校园场景足够） |
| 敏感词双端校验 | 内容安全是社区底线；前端预检省请求 | 语义级违规识别（后端期接模型） |
| 云脑密钥仅存 server | 前端零接触，防 XSS 盗用 | 纯静态环境的云脑（可用本地模型补） |
| 工作流 needConfirm | 写操作人在回路（评审红线） | 一步到位的流畅度（换来可信） |

## 3. 一次"一句话办事"的完整时序

1. 首页输入 → `recognize()` 三层识别（全等 100 / 包含 60+ / 兜底应用检索）
2. 命中工作流 → `engine._preflight()` 槽位预检：缺 → 澄清反问；写操作 → 确认卡
3. Plan 模式 → 先出执行计划卡（步骤预览 + 开始执行/取消），确认后才运行
4. `runWorkflow()` 逐步执行 → `onStep` 实时回传 → UI 耗时计时 + 执行轨迹（默认折叠为摘要）
5. `buildCard()` 结果卡片：rows + actions（openApp / url / agent 追问 / reask 预填）+ 溯源 note
6. 行为落 localStorage（执行计数 / 👎反馈）+ 可选上报 `/api/feedback`
7. 未命中本地 → `/api/chat` 云脑（未配置 501 秒回）→ 兜底话术，**永不干等**

## 4. 换校为什么不塌

- **单一事实来源**：`site.js` 管品牌文案，`agent/config.js` 管大脑文案，`styles.css` 管主题色。
- **正则白名单改写**：`customize.py` 只动 7 个已知落点（含 index.html 标题），改不到内核。
- **数据与代码分离**：`src/data` + `public/data` 全部可替换，视图零修改。
- **端到端回归**：`scripts/smoke-community.mjs` 18 项 + 换校沙盒 7 项 + Wiki 站 2 项，改后必跑。
