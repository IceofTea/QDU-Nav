# 社区治理白皮书（评论 · 校园墙 · 管理台）

## 1. 内容安全三道闸

```
发布前：前端敏感词预检（词库缓存 10 分钟，命中立即提示、不发请求）
发布时：服务端 hitWords 二道闸（命中 → 400 拒绝，hits 回传定位）
发布后：举报 → status=reported → 管理台队列 → 放行 / 隐藏 / 删除
        （删除评论级联删除其楼中楼；全部动作写入审计日志）
```

- 词库维护：管理台「🛡 敏感词」实时增删（默认 29 条广告引流/辱骂类），**改动即刻生效、无需重启、审计留痕**。
- 语义级识别暂缺（不引入未确认依赖），后端期可接审核模型，接口位已预留。

## 2. 准实时与数据一致性

- 前端 15~20s 轮询（`/api/comments/queue?since=` 增量 + 页面回前台即刷）
- 服务端 JSON **原子写**（tmp + rename），断电不损坏
- 网关未连接 → 自动降级本机模式，UI 用 🟡 横幅明示；联网后自动并轨
- **红线：永不假装有数据**——离线时看板/洞察页显示引导语而非编造数字

## 3. 管理台（隐秘入口体系 · 普通用户不可见）

| 入口类型 | 方式 | 防护 |
|---|---|---|
| 晦涩直达 | `/admin` · `/console` · `/.g/9f3a` | `X-Robots-Tag: noindex`，页面标题仅 "Console" |
| 站内暗门 | 导航站**连点 Logo ×3** / Wiki**连点评论徽章 ×5** | 弹口令输入 |
| 口令 | 默认 `qdu-agent-2026`，`ADMIN_TOKEN` 环境变量覆盖 | **失败 5 次/分 锁定 1 分钟** |
| 操作留痕 | 审计日志 200 条（登录 / 审核 / 词库 / 云脑配置） | 管理台「📒 审计」可查 |

**功能分区**：
- 🚩 **举报队列**：置顶待处理，一键放行/隐藏/删除
- 👎 **反馈聚合**：智能体 👎 与"提交反馈"工作流的回流——**Agent 越用越聪明的需求源头**
- 💬 **评论** / 🧱 **帖子**：状态筛选 + 搜索 + 审核三动作
- 🛡 **敏感词**：实时增删
- 🧠 **云脑**：baseUrl/Key/模型配置 + ⚡连通测试（密钥仅存 server，前端永不接触）
- 📒 **审计**：管理操作全留痕

## 4. 积分与悬赏（本地钱包 → 后端期账户体系）

规则见 `src/wall/config.js` POINTS：

| 动作 | 积分 |
|---|---|
| 每日签到 | +2（幂等防重，连续天数统计） |
| 发帖 / 回复 | +2 / +1 |
| 悬赏被采纳（回答方） | +10 |
| 发起悬赏成本 | -5（本地演示不强制扣款，UI 已注明） |

后端期按 `API_CONTRACT` 的 `points/wallet` 迁移；采纳结算走
`POST /api/wall/:id/adopt`（幂等）。

## 5. 广告位策略（俏皮话占位）

- 现阶段：`wall/config.js` 的 `ADS` 常量——侧栏 4 条轮播 + feed 第 3/8 条插槽，
  全部为幽默占位文案（招租/反诈/公益），**零真实商业内容、零跟踪**。
- 后端期：`GET /api/ads?slot=` 返回真广告（含 img/url/clicks）+ 点击计数
  （IP 去重 1 次/天），卡片渲染组件零改动。

## 6. 双 Agent 飞轮（治理与智能化的闭环）

```
用户对话 / 评论 / 👎 / 举报
   ↓ 回流数据池（社区网关）
管理台聚合（反馈队列 · 举报队列 · 热词 · 洞察看板）
   ↓ 维护 Agent 消化（更新 FAQ / 工作流 / 敏感词 / 内容）
服务质量上升 → 用户更愿意开口 → 数据更多
```

量化入口：智能体「协作看板」工作流 + 「📈 社区洞察」应用。
